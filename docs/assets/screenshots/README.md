# Capturas reproduzíveis

Execute `npm run screenshots` depois de instalar o Chromium. O comando gera cinco PNGs ignorados pelo Git para evitar imagens desatualizadas:

- `home-desktop.png`: página inicial em 1440 pixels;
- `catalog-desktop.png`: catálogo em 1440 pixels;
- `wellness-desktop.png`: Central de Bem-Estar em 1440 pixels;
- `admin-desktop.png`: Admin Studio em 1440 pixels;
- `home-mobile.png`: página inicial em 390 pixels.

Revise visualmente e com zoom antes de selecionar capturas para o README ou para a imagem social do repositório. A automação não valida qualidade estética sozinha.
