# Release notes — Saúde Qualimax 3.9.0

## Objetivo

A versão 3.9.0 consolida a Saúde Qualimax como projeto de portfólio técnico, melhorando descoberta, leitura por recrutadores e apresentação da engenharia já existente sem inflar as capacidades do produto.

## Destaques

- README reorganizado para leitura técnica em poucos minutos;
- badges de CI, Pages, versão, acessibilidade, PWA e licença;
- metadados de pacote com keywords, homepage, repositório, issues e autoria;
- Social Preview 1280 × 640 documentada para configuração no GitHub;
- topics e texto do About documentados para descoberta;
- notas automáticas de release categorizadas;
- documentação específica para recrutadores e rastreabilidade da versão;
- versionamento, cache PWA e contratos de regressão sincronizados.

## Evidências preservadas

- 81 páginas HTML;
- 60 produtos orientados por JSON;
- Playwright em desktop e mobile;
- auditoria Axe integrada à CI;
- testes e auditorias Python/Node;
- GitHub Pages e release verificável por SHA-256;
- Admin Studio, White-label Studio, PWA/offline e Max contextual.

## Limites explícitos

A aplicação continua sendo uma plataforma front-end demonstrativa. Não possui backend próprio, autenticação remota, gateway de pagamento, estoque central ou processamento transacional de pedidos.
