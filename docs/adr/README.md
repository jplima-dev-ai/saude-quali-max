# Decisões arquiteturais

Architecture Decision Records preservam contexto, decisão e consequências das escolhas estruturais do projeto.

- [`0001-static-local-first.md`](0001-static-local-first.md) — arquitetura estática e local-first;
- [`0002-accessibility-first.md`](0002-accessibility-first.md) — acessibilidade como contrato;
- [`0003-data-driven-white-label.md`](0003-data-driven-white-label.md) — white-label orientado por dados.

Novas decisões relevantes devem receber um número sequencial. Não reescreva decisões antigas para esconder mudanças: marque o ADR anterior como substituído e crie outro.
